Dúvidas comuns

Perguntas frequentes

Funciona no iPhone?

Por enquanto o Cogni é um app Android.

E se a IA entender errado?

O Cogni mostra uma prévia antes de salvar, então você confere e confirma. Além disso, ele nunca registra como “pago” algo que ainda vai acontecer.

Meus dados ficam seguros?

Cada usuário tem seus dados isolados no Cloud Firestore, protegidos por login com Firebase Authentication.

O CDI usado nas simulações é real?

Sim. O Cogni busca o CDI na API pública do Banco Central (série SGS 12).
